Value Pivot: exercise files

Try each chapter's fixes for yourself. Every exercise starts from the code the AI assistant wrote (the begin state), with a checker that tells you when your fix is right, and one possible answer (the end state) for when you've finished.

Read the chapter first. Then come here, try the exercise, and only open the answer when you've finished or you're truly stuck. Every company, person and figure is fictional, and nothing on these pages is sent anywhere.

In your browser

Open the page and start. There's nothing to install.

Chapter 12. SQL: where the money lives

Five exercises on Harbour Lane Physiotherapy's booking database, which runs inside the page: the double bookings, the £648 December gap, the empty "we miss you" list, the loyalty card, and a database that refuses a double booking itself.

Chapter 13. JavaScript and TypeScript: the types that weren't there

Two exercises on Brightwell Lettings' tenant portal: the field that rode along, and the neighbour's tenancy.

On your computer

Edit the files in an exercise's begin folder, then run python check.py in the chapter's folder. It prints what passes and what doesn't, and writes results.html, which you can open in your browser. Each exercise folder has a README.md with the task.
